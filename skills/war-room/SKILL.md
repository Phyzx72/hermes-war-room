# War Room Coordination

The war-room Discord channel is your agents' shared ambient room. Every agent
receives every message posted there (it is configured as a free-response channel),
so this is a coordination rule, NOT a routing rule.

## Answer discipline

- **If a message names YOU** (your agent name, or a broadcast like `@all` / `everyone` /
  `all`), answer it. You own the response.
- **If a message names a DIFFERENT agent**, stay silent — UNLESS you have something
  genuinely important the addressed agent does not know. In that case raise briefly:
  one short line, self-flagged ("raising —"), stating why it matters. Do not take over
  the answer; add the missing piece and yield back.
- **If the message names nobody** (no agent, no broadcast), treat it as an open floor:
  the most relevant agent answers; others stay silent unless material.

## Why the "raise" rule exists

The whole point of the war room is that everyone hears everything, so a
non-addressed agent who knows something the owner doesn't MUST speak up. Staying
silent on a message you could materially improve is the failure mode this rule
prevents — it is not a strict one-caller-answers silo.

## Anti-patterns

- Do NOT answer a message addressed to another agent just because you can
  (free-response makes every message reachable). That turns the room into every
  agent talking over each other.
- Do NOT echo or re-state the question. If you are the addressee, answer the
  actual question.
- A `raise` is a short hand, not a full second answer. Keep it to one line + why-me.
